# 🏛️ 语法框架体系 (Grammar Blueprint)

本目录用于整理英语的骨架语法体系，打破传统的枯燥死背，采用“逻辑脉络图”来讲解。

> 🎯 **本项目统一世界观**：语法不是权威的规定，而是**一套为“抗噪声通信”而做的工程设计**。  
> 每一条规则都必须回答一个问题：**“英语为什么要这么设计？”**（学员硬性要求）

## 🔜 待建课题（按需推进，不做学院派大纲）

- 过去时与将来时（给乐高装上“时间坐标”零件）
- `can / must / should` 等情态动词（给动词加“态度”零件）
- `there be` 句型与存在表达
- 名词单复数与冠词（`a / the` 的通信功能溯源）
- 从句（用“拼装”思路切入，而非术语灌输）

> 💡 **原则**：只补学员当下真实卡住的地方。**绝不为了“体系完整”而超前灌输**——那正是传统英语教学失败的根源。
